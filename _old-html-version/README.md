# Boxes & Papers by Kaffy: sample website

A sample homepage and store dashboard preview for TBL Kaffy Resources.

## Files

- `index.html`: homepage (bulk price calculator, wholesale catalogue, bulk quote form, cart with Paystack demo)
- `dashboard.html`: order and stock dashboard preview (demo data)
- `assets/css/styles.css`: all styles
- `assets/js/products.js`: product names, prices, stock and WhatsApp number. **Edit this file to change products.**
- `assets/js/main.js`: interactions (calculator, cart, filters, quote form)

## Put it online free (about 2 minutes)

1. Go to https://app.netlify.com/drop
2. Drag the whole `kaffy-website` folder onto the page
3. Copy the link it gives you and send it to Kaffy
4. Optional: in Site settings, rename the site to something like `kaffy-boxes.netlify.app`

Or push to GitHub and import it on Vercel.

## Before sending

- Open `assets/js/products.js` and check the WhatsApp number: `2349043020239`
- Prices and stock are placeholders. Replace them once Kaffy shares her real figures.
- Product images are illustrations. Swap in Kaffy's real photos for the full build.

## For the full build

Online payments, automatic stock, staff accounts and the order dashboard come from
WooCommerce + Paystack. This sample shows how those will look and work.
